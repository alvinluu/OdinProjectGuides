1. What the App Does

MKS Check Balance is a self-service kiosk app for Android tablets. A student or parent scans an account barcode (or types the account ID) and the app instantly shows that account’s spendable balance and most recent deposit — nothing else. It is designed to run unattended on a wall-mounted or counter tablet in landscape orientation.

  • Read-only. It looks up balances; it cannot spend, deposit, or change any account.
  • Locked down. The Android status/navigation bars are hidden and the screen is pinned, so a student cannot exit to other apps.
  • Per-school. Each device is registered to one school and only checks that school’s accounts.
  • Auto-resetting. After a short idle period it clears the screen and returns to a screensaver, so no balance is ever left on display.
At a glance: install → register the device with your school code → set an admin PIN → make it the Home app → mount the tablet and walk away.

2. Install the App

The app is not on the Google Play Store. You download it directly from Odin’s secure download page and install it.

1 On the tablet, open the browser and go to the download page Odin gave you (the Download Balance Checker link).
2 Enter the download password (provided by Odin) and tap Download. The app file (APK) downloads.
3 Open the downloaded file. The first time, Android asks to allow installing unknown apps for the browser — tap Settings → turn on Allow from this source → go back, then tap Install.
4 If Play Protect warns that the app is unrecognized, tap More details → Install anyway.
5 Tap Open to launch it for the first time.
Keep the download password private — anyone with it and the link can download the app. The page serves the app only over a secure (HTTPS) connection.
Updates are handled inside the app, not through a store — Odin controls them from the server (see Section 7). You don’t need the download page again after the first install.

3. First-Time Setup

The very first launch opens the Device Setup screen. This runs once per device.

Register the device (school code)

The app checks whether this tablet is already registered. If not, it shows setup options.

1 Tap Register with school code.
2 Enter your school code (provided by Odin / your administrator) and tap Register.

The device is now tied to that school. A unique device serial (shown at the bottom of the setup screen, e.g. BCA…) identifies this tablet on the server.

Replacing an old tablet? Use Transfer from another device on the setup screen and enter the old tablet’s serial to move its license to the new one.

Admin exit PIN

Right after the school is registered, the app sets up a 6-digit admin PIN. This PIN is what staff use later to exit the kiosk (Section 6).

  • If the school already has a PIN, it is displayed — write it down.
  • If it does not, you’ll be asked to create one. Tap Generate for a random 6-digit code (or type your own), then Save.
Important: Record the admin PIN somewhere safe before tapping Got it. Without it, no one can exit the locked kiosk on this device without reinstalling. The PIN is shared per school, so all that school’s devices use the same code.

4. Make It the Home App (Auto-Launch on Boot)

Setting MKS Check Balance as the Android Home app makes the kiosk start automatically every time the tablet is powered on, and sends the device back to the app whenever the Home button is pressed. This is the recommended kiosk configuration.

1 Press the Android Home button (or restart the tablet).
2 Android asks which launcher to use. Choose MKS Check Balance.
3 Tap Always (not “Just once”) to make it the permanent Home app.

From now on the app opens on every boot with no extra setup.

To undo this later: go to Settings → Apps → Default apps → Home app and pick a different launcher. (You’ll need to exit the kiosk first — see Section 6.)
Note on device names: some Android versions show a one-time “Autostart” permission (Xiaomi, Oppo, Huawei, etc.). If the app doesn’t open on boot, enable Autostart for it in the device’s settings.

5. How the App Works

Scan screen (the main screen)

The home screen shows a full-screen photo background and a single Scan Barcode field that is always ready. Point a connected barcode/QR scanner at an account barcode — the lookup happens automatically and the balance appears. No typing or button press is needed.

  • Works with standard USB/Bluetooth barcode scanners (they act as a keyboard).
  • The app cleans up the scanned code automatically (handles MKS QR codes and ID barcodes).
  • If a barcode isn’t found, the screen shows “Account not found” along with the code that was scanned, then resets.

Manual entry

If there’s no scanner or a barcode won’t read, tap Enter manually.

  • A full-screen pad opens with an on-screen number keypad and keyboard (the device’s own keyboard stays hidden, for kiosk safety).
  • Type the Account ID (or the account’s PIN) and tap Look up.

Balance screen

After a successful lookup, the app shows:

FieldMeaning
Current balanceThe account’s spendable balance (large, at the top).
SchoolThe school this device is registered to.
ID numberThe account’s ID.
PaycodeThe account’s pay category.
Last DepositAmount, date, and reference of the most recent deposit.

A countdown (“Returning to scan in…”) sends the screen back to the main scan screen automatically, or the user can tap Back.

Disabled barcodes: if an account’s barcode has been turned off on the server, the lookup returns “This barcode has been disabled” instead of a balance.

Screensaver & idle reset

After a few minutes of no activity on any screen, the app returns to the main screen and shows a rotating screensaver. Any touch or scan wakes it. This guarantees no account’s balance is ever left visible on an unattended kiosk.

Kiosk lock

While running, the app hides the Android status and navigation bars and pins itself to the screen, so students can’t swipe to other apps, the home screen, or settings. Exiting requires the admin PIN.

6. Exiting the App (Staff)

To leave the kiosk — for updates, settings, or maintenance:

1 Tap the small version number in the top-right corner (e.g. v1.0.0 (2)).
2 A device-info dialog appears (school + device serial). Tap Exit app.
3 Enter the 6-digit admin PIN. It is verified against the server, then the app unpins and closes.
Forgot the PIN? The PIN is stored per school on the server. An administrator can look it up or reset it through Odin. There is no way to bypass it on the device.

7. Updating the App

Updates come from Odin’s server, not Google Play — Odin controls which version each device gets:

  • Automatic (forced): when Odin marks an update as required for a device, the app downloads and installs it on the next launch. On a kiosk provisioned for silent updates this is fully hands-off; otherwise a staff member taps Install once.
  • Manual: tap the version number (top-right) → Check for updates → enter the admin PIN. If a newer version is available it downloads and installs.

You can confirm the installed version any time by reading the number in the top-right corner (v1.0.0 (2) = version 1.0.0, build 2).

After an update: the tablet may briefly show the normal Home launcher chooser again if Android resets defaults. If so, repeat Section 4 to re-select MKS Check Balance as the Home app.

8. Troubleshooting

SymptomWhat to do
Setup shows “This device is not registered”Tap Register with school code and enter your school code. Confirm the tablet has a working network connection.
“Network error” on lookupCheck the tablet’s Wi-Fi / data. The app needs to reach the Odin server to fetch balances.
Scanner does nothingMake sure the scanner is paired/connected and set to act as a keyboard (HID). Test it in the manual-entry field.
“Account not found”The scanned/typed ID isn’t in this school’s accounts, or the barcode is unreadable. Try manual entry.
App didn’t open after rebootRe-select it as the Home app (Section 4); on some brands enable Autostart in device settings.
Need to exit but forgot the PINContact your administrator / Odin to retrieve or reset the school’s admin PIN.
