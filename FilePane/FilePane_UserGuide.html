1. Overview

FilesPane is a native macOS file manager built around multiple independent panes, deep keyboard control, and first-class FTP/SFTP and archive browsing. It's a SwiftUI/AppKit app with no external dependencies — every remote-protocol and archive feature shells out to system tools (curl, sftp/ssh, unzip, ditto) rather than bundling third-party libraries.

2. Panes & Layout

FilesPane splits its window into up to four independent panes. Each pane keeps its own directory, view mode, sort order, column widths, and column visibility — nothing is shared unless you want it to be. The pane-number buttons 1–4 live in the window's title bar, each colored blue/green/orange/purple so panes stay visually distinguishable at a glance, alongside layout and sizing controls.

Showing and Hiding Panes

Use the pane-number buttons (or ⌘2 / ⌘3 / ⌘4) to show or hide pane 2, 3, and 4. Pane 1 is always visible. Every pane stays mounted in the background once shown, so switching back to a hidden pane doesn't reload it from scratch. Move Panes 3 & 4 to a Row Below arranges the four panes as a 2×2 grid instead of a single row, and Equal Size for All Panes (⌘0) resets any dragged divider back to an even split.

Tabs & Dragging a Tab to Split

A pane can hold several tabs; its tab bar appears once there is a second one (View → Show Tab Bar shows or hides it for the active pane). Drag a tab to rearrange or split:

  • Reorder: drag a tab along the tab bar. A marker in the app color shows where it will land. Pinned tabs stay at the left, so a tab can't be dragged across them.
  • Split: drag a tab down onto a pane's body. The side nearest your pointer — left, right, top or bottom — is highlighted in the app color, and dropping splits the pane there, moving the tab into the new pane with its folder, history and selection. If that was the other pane's last tab, the empty pane closes.

A pane's only tab can't split its own pane (there would be nothing left behind).

New Pane Window

The stacked-window icon in the title bar opens a brand-new FilesPane window — the same four-pane layout, sidebar, and toolbar as the main window, starting from whichever pane state (folders browsed, view modes, sort order, column widths, layout) was last saved, exactly like the main window itself would. It's entirely independent while open — nothing in one window is visible in another until something closes. Whichever window you close last — the original main window or one of these copies, it doesn't matter which — is what gets saved, and that's the state FilesPane starts from the next time it opens a window. Useful for a quick side-by-side look at something without disturbing what your main window is currently showing.

The Active Pane

Click anywhere in a pane — or just navigate, select, or type in it — to make it active. The active pane is tinted with a faint accent wash across its toolbar, so with four panes open it's always clear which one your next action (paste, new folder, delete) will affect.

3. View Modes

Every pane can be set to any of six view modes independently, via the view-mode buttons in its toolbar.

ModeDescription
ListA sortable, resizable multi-column table — the classic file-manager view, with per-pane column configuration.
IconsA grid of large icons and names, for browsing by thumbnail.
GalleryOne large preview (with inline video playback) plus a filmstrip of the rest of the folder below it.
StripDense, multi-column vertical lists that reflow to fill the pane's height, each column sized to fit the longest filename it actually contains.
CompactA single scrolling list with a thumbnail, name, and a modified-date-and-size subtitle on each row.
FTPConnects to a remote FTP or SFTP server and browses it in place of the local directory — see FTP & SFTP.
Tip: Switching a pane to FTP and back never disturbs its local directory — the remote connection is entirely separate state, so you always return to exactly where you left off locally.

Zoom

Icon and thumbnail size is adjustable in every view mode: press ⌘+ / ⌘-, hold ⌘ while scrolling over the file listing, or right-click empty space in the pane and pick a size from the Zoom submenu (Small/Medium/Large presets, alongside a submenu for filtering by tag or rating — see Filtering by Tag or Rating). The zoom level is remembered per pane.

4. Navigation & Sidebar

Each pane's toolbar has its own back, forward, and enclosing-folder controls, plus a clickable breadcrumb trail.

The “..” Row

A .. row sits at the top of every listing, showing the name of the enclosing folder. Double-click it to go up one folder — the folder you just left is selected — or drop files on it to move them there. It stays put while you scroll, and it's there in every view mode, inside packages, inside archives (where it goes up a folder, or out to the folder holding the archive) and in Cloud panes (where dropped files upload to the folder above). It's hidden where there's nowhere to go up to, and in Recents, tag and rating lists.

Breadcrumbs

Every folder between your home directory and the current one appears as its own button — click any segment to jump straight there.

Right-click a segment for Copy Path (that folder's own path), Copy Full Path (the whole path shown — the folder you're in) and Go to Folder…, which opens a box where you can type or paste the path of any folder on your Mac (~ works). Pasting a file's path opens its folder with the file selected. The empty space in the toolbar has the same Copy Full Path and Go to Folder items on its own right-click menu.

Filtering

The filter field narrows the current listing to names containing what you type — it doesn't change what's on disk, only what's shown.

The Search window (⌘F) has two scopes. This Folder lists the folder's own matches first, then matches from every folder inside it; This Mac searches every indexed drive. Subfolder matches come from Spotlight, so folders Spotlight doesn't index only show their own items.

Sidebar

The window's sidebar has four sections:

  • Recents — see Recents below.
  • Favorites — Home, Desktop, Documents, Downloads, Applications, and Trash, plus any folders you've bookmarked yourself (see Bookmarks).
  • Files — a live, expandable directory tree that tracks whichever folder the active pane is showing.
  • Volumes — every mounted volume, including external and USB drives, exactly as macOS mounts them under /Volumes.

Recents

Click Recents in the sidebar to show recently-used files — backed by Spotlight, the same mechanism Finder's own Recents uses. A thin banner across the top of the pane (with a close button) makes it clear you're looking at a snapshot rather than a real folder. Recents renders through whichever view mode the pane is already in — List, Compact, Icons, Gallery, or Strip — so it looks and behaves like the rest of that pane, including rename, tagging, rating, and Move to Trash. Navigating anywhere (breadcrumb, Back, Most Visited, or opening a folder) automatically leaves Recents and returns to normal browsing.

Most Visited Folders

Each pane's breadcrumb row has a Most Visited dropdown listing the folders you actually work in, ranked by how long you've dwelled in them (a folder only counts as a “visit” once you've stayed on it for a full 10 minutes, not just passed through). Recents is always pinned at the top of the list regardless of visit history.

5. Bookmarks

A Chrome-style bookmark bar sits just below the title bar, letting you save quick-access folders and organize them into folders of your own — separate from (but built on top of) the same Favorites list the sidebar shows.

The Bookmark Bar

Toggle the bar on or off with the bookmark-icon button in the toolbar. Drag any folder onto the bar's blank space to bookmark it, or right-click the blank space for Add Path… (choose an existing folder from a file picker) and New Folder… (create an empty organizing folder). The same blank-space menu also has Bookmark Manager…, which opens the full manager window (see below).

Clicking a bookmark while the active pane is showing a Cloud (FTP/SFTP) listing asks Leave Cloud? first — a bookmark is a folder on your Mac, so it can't open inside Cloud. Choose Leave Cloud to switch that pane to the normal view and open the folder, or Stay in Cloud to cancel. Your Cloud connection stays open either way, so switching the pane back to Cloud picks up where you left off.

Folders vs. Paths

Every item on the bar is one of two kinds, and FilesPane is deliberate about keeping the two visually and terminologically distinct — the same split Chrome itself makes between a bookmark (a URL) and a folder (an organizing container), just applied to real filesystem locations instead of web pages:

  • Path — a saved reference to a real folder on disk. Shows that folder's own genuine icon, exactly as Finder would draw it. Can be given a custom display name independent of the real folder's name (right-click → Rename…), the same way Chrome lets you rename any bookmark's title.
  • Folder — a purely organizational container with no filesystem location of its own; it just holds other Paths and Folders. Shown with a yellow filled-folder icon specifically so it's never mistaken for a Path pointing at a real folder that happens to look similar.

Opening a Folder's Dropdown

Click a Folder on the bar to open a small floating dropdown listing its contents. A Path row inside it navigates on click; a nested Folder row drills one level deeper into its own contents, with a ‹ Back row at the top to return. Rows highlight as the mouse moves over them, the same as any menu.

Right-clicking a Folder shows the same contents directly in its context menu — a Path row navigates, and a nested Folder row becomes a native submenu that opens on hover, recursing to any depth — followed by Rename Folder… and Remove Folder. This lets you browse into a folder and manage it from one right-click, without needing the separate left-click dropdown. Right-clicking the dropdown's own blank space offers Bookmark Manager… too.

Drag and Drop

  • Drag a real folder (from Finder, a pane, or the sidebar) onto a bookmark Folder to bookmark it inside that Folder.
  • Drag an existing bookmark onto a Folder to move it there instead of re-adding it.
  • Hovering a drag over a Folder button for about half a second automatically opens its dropdown, Chrome-style, so you can drop directly into a nested Folder shown inside it without letting go first.
  • Dragging a real folder onto a plain Path bookmark moves the dragged item(s) into that Path's own real folder on disk — the same "drop onto a folder shortcut to move into it" behavior as Finder's sidebar.
Note: Removing a Path always asks for confirmation first, showing the real filesystem path that will be removed — since a Path's display name can now be a custom rename with no visible resemblance to the actual folder.

The Bookmark Manager

Open it from the bar's own right-click menu, or a Folder's dropdown/context menu. It's a two-pane window: a folder tree on the left (every Folder, nested to any depth, under an implicit "Bookmarks" root), and the selected folder's direct contents — Paths and Folders together, in order — on the right.

  • Drag a row to reorder it within its current folder, or drop it onto a folder in either pane to reparent it there.
  • Drag a real folder in from Finder to bookmark it directly into whatever folder is showing.
  • New Folder and Delete are in the toolbar; right-click a row for Rename/Open/Remove.
  • Double-click a Path to open it in the frontmost FilesPane window; double-click a Folder to browse into it.

Import & Export (CSV)

The Manager's toolbar has Export CSV… and Import CSV… buttons. Export writes every bookmark and folder to a CSV file (defaulting to a name like FilesPane_bookmark_2026-09-13.csv), with each folder's position recorded as a "/"-joined chain of ancestor folder names rather than internal IDs, so the file stays human-readable and hand-editable. Import reads that same format back, recreating folders (by name) and Paths under them — new rows are always added rather than merged with anything already there, so review the result afterward if you're re-importing into a Manager that already has bookmarks.

6. Working with Files

Selections, clipboard, drag-and-drop, and undo all work the way you'd expect from a Mac file manager — with a few deliberate upgrades.

Copy, Cut, Paste, Duplicate

Standard ⌘C / ⌘X / ⌘V, plus Duplicate from the context menu. A name collision at the destination never silently overwrites or silently renames — see Conflicts below.

Drag and Drop

Drag files between panes, in from Finder, or out to Finder — all of it registers proper multi-step undo. Dragging into a different folder moves the file (matching Cut+Paste); the same conflict handling applies.

Conflicts: Replace, Keep Both, or Skip

When a drag-and-drop or Cut+Paste move collides with an existing name, FilesPane stops and asks:

ChoiceWhat happens
ReplaceThe existing item is moved to Trash first — fully recoverable — then the new one takes its place.
Keep BothThe incoming item is renamed name copy 2, name copy 3, and so on.
SkipThat one item is left where it was; everything else in the batch still proceeds.

Moving several files at once shows an Apply to all remaining conflicts option so you don't have to answer the same question repeatedly.

Tags, Rename, Alias, Info

The context menu shows a horizontal row of clickable colored tag dots — matching Finder's own context menu — right above a labeled Tags… submenu for anyone who prefers to see tag names spelled out. Rename happens in place: the filename itself becomes editable directly in its row or cell (press Return to commit, Escape to cancel), the same way Finder's own rename works, rather than a separate popup dialog. While you rename, the text cursor is a thick red bar and selected text is strongly highlighted, so both are easy to spot. Create an alias, or open Get Info.

Get Info (⌘I) opens a Finder-style window for the item, and you can keep several open at once. Its sections can be collapsed: General (kind, exact size and size on disk with an item count for folders, location, dates, Locked), More Info (where it was downloaded from, last opened, dimensions), Name & Extension (rename, Hide extension), Comments, Preview and Sharing & Permissions (owner, group and everyone, editable on items you own). Tags can be added or removed at the top. With several items selected, Get Info opens one summary window instead: the total size of everything selected (folders are measured all the way down), how many files and folders, where they are, and each item's own size, largest first.

Star Ratings

Right-click a file and choose a rating from the Rating submenu (No Rating through 5 stars), or click the stars directly in the Preview window's header — clicking the star that's already the current rating clears it. Ratings write to the same kMDItemStarRating Spotlight attribute Finder's own (now-removed) rating widget used to, so they're visible to Spotlight and any other rating-aware app, not just FilesPane. Star ratings show in Gallery's main preview, Compact view's info line, and the Preview window, and can be used to filter a pane's listing — see Filtering by Tag or Rating.

Compress & Extract

Compress builds a .zip from the current selection. Compress As (right-click menu) builds the same archive in another format — .zip, .tar.gz, .tar.xz, .tar.bz2 or .7z (.rar can be opened but not created). If the archive can't be built, an error is shown and no partial file is left behind. Extract unpacks an existing archive (.zip, .tar, .tar.gz/.tgz, .tar.bz2, .tar.xz, .7z or .rar) into a new sibling folder named after it, with the progress window showing how much has been written (against the total for a .zip) and a Cancel button that also removes the half-extracted folder. For looking inside an archive without unpacking it at all, see Archive Browsing.

Trash & Undo

Whenever something is selected, Trash, Copy, Cut, and Paste buttons appear in the pane's footer (at the bottom, next to the item-count text) for quick access without a context menu. Empty Trash is available from a folder's background context menu when you're browsing it. Nearly every destructive or move-like action — trash, move, paste, duplicate, rename — is undoable with ⌘Z and redoable with ⇧⌘Z. Every one of these changes is also recorded in File History, which can undo most of them directly even after they've scrolled off the pane's own undo stack.

7. Columns, Sorting & Sizes

List and Compact views are backed by a real, sortable column system — configured independently per pane.

Per-Pane Columns

Each pane remembers its own visible columns and column widths — hiding the Kind column in one pane, or widening Date Modified in another, never affects any other pane. Available columns: Size, Kind, Date Modified, Date Created, Last Opened, and Permissions.

Sorting

Click a column header, or use the Sort-By menu in the toolbar, to sort by Name, Size, Kind, Date Modified, Date Created, or Last Opened. The same menu has explicit Ascending and Descending entries below the sort keys — or just click the same key again to flip direction. Folders always sort ahead of files, regardless of key.

Filtering by Tag or Rating

The toolbar's filter icon (next to Sort) narrows the current listing by tag and/or a minimum star rating — e.g. only files tagged Red, or only files rated 4 stars and up. It combines with the text filter field, and on a narrow pane the whole group of view-mode/sort/filter/translation controls drops to its own row instead of getting cramped.

Real Sizes for Packages

An app bundle (.app) or other package is really a folder on disk, so its size isn't known up front. FilesPane shows -- immediately, then computes the real, recursive size in the background and fills it in — the same way Finder does, without stalling the folder you're looking at while it works.

8. Previews & Thumbnails

  • Quick Look — press Space on a selection for the system Quick Look panel.
  • Preview window (⌘Y, or "Open in Preview Window" from the context menu) — a dedicated floating window with its own filmstrip, so you can flip through every previewable file in the folder without leaving Quick Look behind. Its footer has Trash, Rename, Move to…, Open With, and Open buttons, and its header shows clickable star-rating dots for the current file.
  • Documents — Word-style documents (.doc, .docx, .rtf, .odt, .pages) open in the Preview window as a real, scrollable, multi-page document rather than a single static page.
  • Gallery playback — video files play back directly, inline, in Gallery view's large preview pane.
  • Thumbnails — generated in the background and cached, so scrolling a large folder never waits on them.

9. Interface Details

Tooltips

Hovering any toolbar control shows a short tooltip below the pointer, timed to avoid flickering under a moving cursor. Near a window edge it moves above the pointer or shifts sideways so it stays fully on screen, and long tooltips wrap. Tooltips for anything with a keyboard shortcut show the shortcut too.

Title Bar & Window Title

The pane-number buttons, New Pane Window button, layout toggle, and equal-size button live directly in the window's title bar.

Text Size

Text size is set in Settings → Appearance with two sliders: App Text Size scales the toolbars, sidebar and menus (the layout grows to fit), while File List Text Size changes only the rows in the file panes. A percentage next to each slider shows where you are.

Settings

Click the gear in the toolbar to open Settings — a large window with a sidebar of pages on the left and the selected page's options on the right. Close it with the Close button or Esc.

  • General — your version, this User Guide, Send Feedback, and Keyboard Shortcuts.
  • Appearance — Light, Dark, or Custom color mode (with an app color picker and a Reset to Default), and the two text-size sliders.
  • Files — Default View and Default Sort for panes, and Folder & Disk Access.
  • Tools — Sync Manager, Duplicate File Manager and Large File Finder. These are Pro features; without a trial or license this page shows a single Unlock Pro Features entry instead.
  • License — see below.

Large File Finder

Finds every file over a size you pick in a folder and everything inside it — hidden files included — and also checks the Trash on every drive. Each result says what it is in plain words (for example Xcode build data — safe to delete, iPhone/iPad backup, Docker virtual disk, App cache) and is marked Hidden or In Trash when it applies. Files that were deleted but are still held open by an app are listed too, with that app's name — their space comes back once you quit the app. Selected files are deleted permanently.

Default Pane View & Sort

Under Settings → Files → Default View, choose the view (List, Icons, Gallery, Strip or Compact) that new windows and new panes start in. It applies only to panes that don't already have a view of their own: panes you've already set up keep what they're using, and a new tab or split still matches the pane it came from. Cloud isn't offered, since it needs a live connection. Default Sort, just below it, sets the sort column (Name, Size, Kind, Date Modified, Date Created or Last Opened) and its direction the same way.

Folder & Disk Access

The first time FilesPane opens, it shows a Folder & Disk Access screen. Use Add Folder… (as many times as you like, or select several folders at once) to choose the folders you plan to use — picking a folder here grants access immediately, so macOS doesn't interrupt you with a permission prompt for it later. The same screen explains Full Disk Access, which macOS never asks for on its own: open System Settings → Privacy & Security → Full Disk Access, turn on FilesPane, and relaunch FilesPane if it's already running. The Open System Settings… button jumps straight there.

You can skip the screen — macOS will still ask the first time FilesPane touches a protected folder. To reopen it later, go to Settings → Files → Folder & Disk Access….

License

Settings → License shows where your license stands.

  • Licensed (Pro) — your license key, this Mac's device name, and the date your included updates run through. The key is hidden (all but its last four characters) until you press Show; Copy always copies the full key, for support or when moving the license to another Mac.
  • Trial, ended, or unverified — the status (for example "Trial: 9 days left"), plus Enter License… to activate a key and Buy a License.

If the version you're running was released after your license's update window ended, FilesPane shows a one-time notice per launch. Nothing is locked — you can keep using that version — and the notice states the date your license covers, offers a Download button for the newest version released within it (when available), and a Renew button for newer releases.

10. Filename Translation

Compact view can show a translated version of each filename alongside the original — handy when browsing a folder whose files are named in a language you don't read fluently.

Turning It On

A translate button appears in the toolbar, but only while a pane is in Compact view. Turning it on reveals a target-language menu (English by default); the source language is detected automatically per file, so it works regardless of what language the names are actually in.

Tip: Translation is Compact-view-only by design. Switching to another view mode hides the controls and stops translating in the background until you switch back to Compact.

How It Works

FilesPane uses Apple's on-device Translation framework — free, offline, no API key required. Translated names appear as a secondary line under each filename, computed in the background so browsing never waits on it; rows grow slightly taller in Compact view to fit the extra line. Results are cached per file and target language, so switching back to a language you've already used shows results instantly, and switching languages properly refreshes what's on screen.

Renaming to the Translated Name

Right-click a file with a translated name showing and choose Rename to Translated Name to actually rename it on disk — this goes through the same rename path as a manual rename, so it's undoable and shows up in File History.

Note: Requires macOS 15 or later. On earlier versions the translate button simply doesn't appear — everything else in FilesPane is unaffected.

11. FTP & SFTP

Set a pane's view mode to FTP to connect to a remote server and browse it with the same read-write capability as a local folder.

Connecting

The login screen offers FTP (with optional FTPS) and SFTP, a Test Connection button before you commit, and a saved-profiles picker that can Rename, Duplicate, or Delete any profile. FilesPane remembers the last profile you connected with and pre-selects it next time.

Full Read-Write

Upload, download, rename, delete, and create folders — the remote toolbar mirrors a local pane's: back/forward/up, breadcrumb, filter, and a sort menu, all driving the remote listing instead of the local one.

Copy, Paste & Drag-and-Drop with Remote Files

⌘C / ⌘V and drag-and-drop work in both directions:

  • Local files copied or dragged onto an FTP pane are uploaded.
  • Remote files copied, dragged out, or pasted into a local pane are downloaded.
  • Copying between two remote locations downloads to a temporary file and re-uploads it, since neither FTP nor SFTP has a native server-side copy command — cutting within the same server uses a real rename instead, which is instant.

The same Replace / Keep Both / Skip conflict handling from local drag-and-drop applies here too.

Note: Replacing a remote file can't be undone. Unlike local Replace (which uses Trash), FTP/SFTP servers have no recycle bin — a replaced remote file is genuinely overwritten.

12. Archive Browsing

Double-click a .zip, .tar, .tar.gz/.tgz, .tar.bz2/.tbz2, .tar.xz/.txz, .7z or .rar file to look inside it — without extracting anything to disk. (Right-click → Browse Archive does the same, and Extract is still there when you do want the files on disk.)

  • Navigate into folders inside the archive, as many levels deep as it goes, exactly like a real directory, with back/forward/up, a breadcrumb and the .. row. Going back or up from the archive's top level closes it and returns to the folder holding it, with the archive selected.
  • Double-click a file to extract it to a temporary location and open it with its default application.
  • Extract To… pulls one or more selected entries out to a folder you choose, with progress shown item by item.
  • Copy files out with ⌘C, or drag them straight onto a local pane or Finder.

Archive browsing is read-only — it won't add to or modify the archive in place — and folders inside an archive aren't drag- or copy-able as a whole yet, only individual files.

Packages

Double-clicking a package — a folder that Finder presents as a single file, such as an .rtfd document or an Xcode project — opens it as a regular folder in the pane, like Finder's Show Package Contents. Applications are the exception: double-clicking an .app still launches it.

13. File History

The clock icon in the main toolbar (next to the file-tree toggle), or ⌘⇧H, opens a running log of every file change FilesPane has made — local, FTP/SFTP, and archive extractions alike. Clear History sits at the left of the History window's header.

What Gets Logged

  • Local — create, rename, move, copy, duplicate, move to Trash, restore from Trash, empty Trash, compress, extract, tag/untag, make alias.
  • FTP/SFTP — upload, download, delete, rename, create folder, and remote-to-remote transfers.
  • Archive browsing — extracting a file out of a .zip.
  • Preview window — Move to Trash and Move to… from the preview window's own toolbar.

Each entry shows a plain-English summary and a timestamp. Use the filter field to search, or right-click an entry for Reveal in Finder and Copy Path.

Undo From History

Many entries show an Undo button — a real reversal against the filesystem, independent of any pane's own ⌘Z stack, so it works even when the entry isn't the most recent thing that pane would undo:

KindWhat Undo does
Renamed, MovedMoves the item back to where it was.
Moved to TrashRestores it from Trash.
Restored from TrashRe-trashes it.
Created, Copied, Duplicated, Alias Created, Compressed, Extracted, Extracted from ArchiveTrashes the created item — recoverable, never a hard delete.
Tagged, UntaggedToggles the same tag back off/on.

The Undo button only appears while the reversal is still valid — it re-checks the live filesystem each time, so it disappears once you've already undone it or the file has since moved on. Undoing something is itself logged as a new entry, so it stays undoable in turn.

Note: Not undoable from History: anything on a remote FTP/SFTP server (needs a live connection History doesn't have), permanent deletes (nothing left to restore), and a Replace from a drag-and-drop conflict (a plain reverse move wouldn't also bring back the item Replace trashed).

Clearing History

Clear History asks for confirmation first, since it also removes the Undo capability for anything still listed.

14. Keyboard Shortcuts

Everything that has a shortcut also has a menu-bar entry, with its shortcut shown beside it: File (new tab and folder, open, Quick Look, Get Info, rename, duplicate, alias, copy/move to, compress, share, reveal, trash), Edit (undo, cut, copy, paste, select all, copy path, search), View (view as, sort by, hidden files, thumbnails, bookmarks bar, the active pane's tab bar, zoom, refresh, split), Go (back, forward, enclosing folder, Recents, your main folders, Go to Folder) and Tools (File History, Bookmark Manager, duplicate and large-file finders, sync, shortcut editor). The menus act on the active pane, show a check mark beside the current view and sort, and grey out what doesn't apply — for example, items that need a selection while nothing is selected. A shortcut you change in the editor changes in the menu too.

Per-pane shortcuts apply to whichever pane is active; window-level shortcuts apply regardless of which pane is active.

15. Good to Know

  • Drag, drop, and copy — whether local, FTP/SFTP, or inside an archive — currently move individual files; whole folders aren't transferred recursively yet in those paths.
  • FTP/SFTP folder-to-folder transfers and archive extraction are real, disk-backed operations, so very large transfers take the time they take — there's no separate background queue.
  • Archive browsing supports .zip, tar (plain, gzip, bzip2, xz), .7z and .rar. A lone .gz, .bz2 or .xz file (not a tar) isn't treated as an archive.
  • Filename translation requires macOS 15 or later and only appears in Compact view.
  • File History can undo most local file operations, but not remote (FTP/SFTP) changes or permanent deletes — see Undo From History.
  • Importing a bookmarks CSV always adds new rows rather than merging with what's already in the Bookmark Manager — review the result if you're re-importing into a Manager that isn't empty.
