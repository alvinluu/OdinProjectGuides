1. Overview

FilePane is a native macOS file manager built around multiple independent panes, deep keyboard control, and first-class FTP/SFTP and archive browsing. It's a SwiftUI/AppKit app with no external dependencies — every remote-protocol and archive feature shells out to system tools (curl, sftp/ssh, unzip, ditto) rather than bundling third-party libraries.

2. Panes & Layout

FilePane splits its window into up to four independent panes. Each pane keeps its own directory, view mode, sort order, column widths, and column visibility — nothing is shared unless you want it to be. The pane-number buttons 1–4 live in the window's title bar, each colored blue/green/orange/purple so panes stay visually distinguishable at a glance, alongside layout and sizing controls.

Showing and Hiding Panes

Use the pane-number buttons (or ⌘2 / ⌘3 / ⌘4) to show or hide pane 2, 3, and 4. Pane 1 is always visible. Every pane stays mounted in the background once shown, so switching back to a hidden pane doesn't reload it from scratch. Move Panes 3 & 4 to a Row Below arranges the four panes as a 2×2 grid instead of a single row, and Equal Size for All Panes (⌘0) resets any dragged divider back to an even split.

New Pane Window

The stacked-window icon in the title bar opens a brand-new FilePane window — the same four-pane layout, sidebar, and toolbar as the main window, starting from whichever pane state (folders browsed, view modes, sort order, column widths, layout) was last saved, exactly like the main window itself would. It's entirely independent while open — nothing in one window is visible in another until something closes. Whichever window you close last — the original main window or one of these copies, it doesn't matter which — is what gets saved, and that's the state FilePane starts from the next time it opens a window. Useful for a quick side-by-side look at something without disturbing what your main window is currently showing.

The Active Pane

Click anywhere in a pane — or just navigate, select, or type in it — to make it active. The active pane is tinted with a faint accent wash across its toolbar, so with four panes open it's always clear which one your next action (paste, new folder, delete) will affect.

3. View Modes

Every pane can be set to any of six view modes independently, via the view-mode buttons in its toolbar.

ModeDescription
ListA sortable, resizable multi-column table — the classic file-manager view, with per-pane column configuration.
IconsA grid of large icons and names, for browsing by thumbnail.
GalleryOne large preview (with inline video playback) plus a filmstrip of the rest of the folder below it.
StripDense, multi-column vertical lists that reflow to fill the pane's height, each column sized to fit the longest filename it actually contains.
CompactA single scrolling list with a thumbnail, name, and a modified-date-and-size subtitle on each row.
FTPConnects to a remote FTP or SFTP server and browses it in place of the local directory — see FTP & SFTP.
Tip: Switching a pane to FTP and back never disturbs its local directory — the remote connection is entirely separate state, so you always return to exactly where you left off locally.

Zoom

Icon and thumbnail size is adjustable in every view mode: press ⌘+ / ⌘-, hold ⌘ while scrolling over the file listing, or right-click empty space in the pane and pick a size from the Zoom submenu (Small/Medium/Large presets, alongside a submenu for filtering by tag or rating — see Filtering by Tag or Rating). The zoom level is remembered per pane.

4. Navigation & Sidebar

Each pane's toolbar has its own back, forward, and enclosing-folder controls, plus a clickable breadcrumb trail.

Breadcrumbs

Every folder between your home directory and the current one appears as its own button — click any segment to jump straight there, or right-click one to copy its path.

Filtering

The filter field narrows the current listing to names containing what you type — it doesn't change what's on disk, only what's shown.

Sidebar

The window's sidebar has four sections:

  • Recents — see Recents below.
  • Favorites — Home, Desktop, Documents, Downloads, Applications, and Trash, plus any folders you've added yourself.
  • Files — a live, expandable directory tree that tracks whichever folder the active pane is showing.
  • Volumes — every mounted volume, including external and USB drives, exactly as macOS mounts them under /Volumes.

Recents

Click Recents in the sidebar to show recently-used files — backed by Spotlight, the same mechanism Finder's own Recents uses. A thin banner across the top of the pane (with a close button) makes it clear you're looking at a snapshot rather than a real folder. Recents renders through whichever view mode the pane is already in — List, Compact, Icons, Gallery, or Strip — so it looks and behaves like the rest of that pane, including rename, tagging, rating, and Move to Trash. Navigating anywhere (breadcrumb, Back, Most Visited, or opening a folder) automatically leaves Recents and returns to normal browsing.

Most Visited Folders

Each pane's breadcrumb row has a Most Visited dropdown listing the folders you actually work in, ranked by how long you've dwelled in them (a folder only counts as a “visit” once you've stayed on it for a full 10 minutes, not just passed through). Recents is always pinned at the top of the list regardless of visit history.

5. Working with Files

Selections, clipboard, drag-and-drop, and undo all work the way you'd expect from a Mac file manager — with a few deliberate upgrades.

Copy, Cut, Paste, Duplicate

Standard ⌘C / ⌘X / ⌘V, plus Duplicate from the context menu. A name collision at the destination never silently overwrites or silently renames — see Conflicts below.

Drag and Drop

Drag files between panes, in from Finder, or out to Finder — all of it registers proper multi-step undo. Dragging into a different folder moves the file (matching Cut+Paste); the same conflict handling applies.

Conflicts: Replace, Keep Both, or Skip

When a drag-and-drop or Cut+Paste move collides with an existing name, FilePane stops and asks:

ChoiceWhat happens
ReplaceThe existing item is moved to Trash first — fully recoverable — then the new one takes its place.
Keep BothThe incoming item is renamed name copy 2, name copy 3, and so on.
SkipThat one item is left where it was; everything else in the batch still proceeds.

Moving several files at once shows an Apply to all remaining conflicts option so you don't have to answer the same question repeatedly.

Tags, Rename, Alias, Info

The context menu shows a horizontal row of clickable colored tag dots — matching Finder's own context menu — right above a labeled Tags… submenu for anyone who prefers to see tag names spelled out. Rename happens in place: the filename itself becomes editable directly in its row or cell (press Return to commit, Escape to cancel), the same way Finder's own rename works, rather than a separate popup dialog. Create an alias, or open Get Info for size, kind, dates, permissions, and tags at a glance.

Star Ratings

Right-click a file and choose a rating from the Rating submenu (No Rating through 5 stars), or click the stars directly in the Preview window's header — clicking the star that's already the current rating clears it. Ratings write to the same kMDItemStarRating Spotlight attribute Finder's own (now-removed) rating widget used to, so they're visible to Spotlight and any other rating-aware app, not just FilePane. Star ratings show in Gallery's main preview, Compact view's info line, and the Preview window, and can be used to filter a pane's listing — see Filtering by Tag or Rating.

Compress & Extract

Compress builds a .zip from the current selection. Extract unpacks an existing .zip into a new sibling folder. For inspecting a zip without unpacking it at all, see Archive Browsing.

Trash & Undo

Whenever something is selected, Trash, Copy, Cut, and Paste buttons appear in the pane's footer (at the bottom, next to the item-count text) for quick access without a context menu. Empty Trash is available from a folder's background context menu when you're browsing it. Nearly every destructive or move-like action — trash, move, paste, duplicate, rename — is undoable with ⌘Z and redoable with ⇧⌘Z. Every one of these changes is also recorded in File History, which can undo most of them directly even after they've scrolled off the pane's own undo stack.

6. Columns, Sorting & Sizes

List and Compact views are backed by a real, sortable column system — configured independently per pane.

Per-Pane Columns

Each pane remembers its own visible columns and column widths — hiding the Kind column in one pane, or widening Date Modified in another, never affects any other pane. Available columns: Size, Kind, Date Modified, Date Created, Last Opened, and Permissions.

Sorting

Click a column header, or use the Sort-By menu in the toolbar, to sort by Name, Size, Kind, Date Modified, Date Created, or Last Opened. The same menu has explicit Ascending and Descending entries below the sort keys — or just click the same key again to flip direction. Folders always sort ahead of files, regardless of key.

Filtering by Tag or Rating

The toolbar's filter icon (next to Sort) narrows the current listing by tag and/or a minimum star rating — e.g. only files tagged Red, or only files rated 4 stars and up. It combines with the text filter field, and on a narrow pane the whole group of view-mode/sort/filter/translation controls drops to its own row instead of getting cramped.

Real Sizes for Packages

An app bundle (.app) or other package is really a folder on disk, so its size isn't known up front. FilePane shows -- immediately, then computes the real, recursive size in the background and fills it in — the same way Finder does, without stalling the folder you're looking at while it works.

7. Previews & Thumbnails

  • Quick Look — press Space on a selection for the system Quick Look panel.
  • Preview window (⌘Y, or "Open in Preview Window" from the context menu) — a dedicated floating window with its own filmstrip, so you can flip through every previewable file in the folder without leaving Quick Look behind. Its footer has Trash, Rename, Move to…, Open With, and Open buttons, and its header shows clickable star-rating dots for the current file.
  • Gallery playback — video files play back directly, inline, in Gallery view's large preview pane.
  • Thumbnails — generated in the background and cached, so scrolling a large folder never waits on them.

8. Interface Details

Tooltips

Hovering any toolbar control shows a short tooltip positioned to the right, timed to avoid flickering under a moving cursor. Tooltips for anything with a keyboard shortcut show the shortcut too.

Title Bar & Window Title

The pane-number buttons, New Pane Window button, layout toggle, and equal-size button live directly in the window's title bar.

Text Size

The font-size button in the toolbar cycles through a few UI scales — a percentage briefly appears in place of the icon so you can see exactly where you landed.

9. Filename Translation

Compact view can show a translated version of each filename alongside the original — handy when browsing a folder whose files are named in a language you don't read fluently.

Turning It On

A translate button appears in the toolbar, but only while a pane is in Compact view. Turning it on reveals a target-language menu (English by default); the source language is detected automatically per file, so it works regardless of what language the names are actually in.

Tip: Translation is Compact-view-only by design. Switching to another view mode hides the controls and stops translating in the background until you switch back to Compact.

How It Works

FilePane uses Apple's on-device Translation framework — free, offline, no API key required. Translated names appear as a secondary line under each filename, computed in the background so browsing never waits on it; rows grow slightly taller in Compact view to fit the extra line. Results are cached per file and target language, so switching back to a language you've already used shows results instantly, and switching languages properly refreshes what's on screen.

Renaming to the Translated Name

Right-click a file with a translated name showing and choose Rename to Translated Name to actually rename it on disk — this goes through the same rename path as a manual rename, so it's undoable and shows up in File History.

Note: Requires macOS 15 or later. On earlier versions the translate button simply doesn't appear — everything else in FilePane is unaffected.

10. FTP & SFTP

Set a pane's view mode to FTP to connect to a remote server and browse it with the same read-write capability as a local folder.

Connecting

The login screen offers FTP (with optional FTPS) and SFTP, a Test Connection button before you commit, and a saved-profiles picker that can Rename, Duplicate, or Delete any profile. FilePane remembers the last profile you connected with and pre-selects it next time.

Full Read-Write

Upload, download, rename, delete, and create folders — the remote toolbar mirrors a local pane's: back/forward/up, breadcrumb, filter, and a sort menu, all driving the remote listing instead of the local one.

Copy, Paste & Drag-and-Drop with Remote Files

⌘C / ⌘V and drag-and-drop work in both directions:

  • Local files copied or dragged onto an FTP pane are uploaded.
  • Remote files copied, dragged out, or pasted into a local pane are downloaded.
  • Copying between two remote locations downloads to a temporary file and re-uploads it, since neither FTP nor SFTP has a native server-side copy command — cutting within the same server uses a real rename instead, which is instant.

The same Replace / Keep Both / Skip conflict handling from local drag-and-drop applies here too.

Note: Replacing a remote file can't be undone. Unlike local Replace (which uses Trash), FTP/SFTP servers have no recycle bin — a replaced remote file is genuinely overwritten.

11. Archive Browsing

Right-click any .zip and choose Browse Archive to look inside it — without extracting anything to disk.

  • Navigate into folders inside the archive exactly like a real directory, with back/forward/up and a breadcrumb.
  • Double-click a file to extract it to a temporary location and open it with its default application.
  • Extract To… pulls one or more selected entries out to a folder you choose.
  • Copy files out with ⌘C, or drag them straight onto a local pane or Finder.

Archive browsing is read-only — it won't add to or modify the zip in place — and folders inside an archive aren't drag- or copy-able as a whole yet, only individual files.

12. File History

The clock icon in the main toolbar (next to the file-tree toggle), or ⌘⇧H, opens a running log of every file change FilePane has made — local, FTP/SFTP, and archive extractions alike. Clear History sits at the left of the History window's header.

What Gets Logged

  • Local — create, rename, move, copy, duplicate, move to Trash, restore from Trash, empty Trash, compress, extract, tag/untag, make alias.
  • FTP/SFTP — upload, download, delete, rename, create folder, and remote-to-remote transfers.
  • Archive browsing — extracting a file out of a .zip.
  • Preview window — Move to Trash and Move to… from the preview window's own toolbar.

Each entry shows a plain-English summary and a timestamp. Use the filter field to search, or right-click an entry for Reveal in Finder and Copy Path.

Undo From History

Many entries show an Undo button — a real reversal against the filesystem, independent of any pane's own ⌘Z stack, so it works even when the entry isn't the most recent thing that pane would undo:

KindWhat Undo does
Renamed, MovedMoves the item back to where it was.
Moved to TrashRestores it from Trash.
Restored from TrashRe-trashes it.
Created, Copied, Duplicated, Alias Created, Compressed, Extracted, Extracted from ArchiveTrashes the created item — recoverable, never a hard delete.
Tagged, UntaggedToggles the same tag back off/on.

The Undo button only appears while the reversal is still valid — it re-checks the live filesystem each time, so it disappears once you've already undone it or the file has since moved on. Undoing something is itself logged as a new entry, so it stays undoable in turn.

Note: Not undoable from History: anything on a remote FTP/SFTP server (needs a live connection History doesn't have), permanent deletes (nothing left to restore), and a Replace from a drag-and-drop conflict (a plain reverse move wouldn't also bring back the item Replace trashed).

Clearing History

Clear History asks for confirmation first, since it also removes the Undo capability for anything still listed.

14. Good to Know

  • Drag, drop, and copy — whether local, FTP/SFTP, or inside an archive — currently move individual files; whole folders aren't transferred recursively yet in those paths.
  • FTP/SFTP folder-to-folder transfers and archive extraction are real, disk-backed operations, so very large transfers take the time they take — there's no separate background queue.
  • Archive browsing currently supports .zip only.
  • Filename translation requires macOS 15 or later and only appears in Compact view.
  • File History can undo most local file operations, but not remote (FTP/SFTP) changes or permanent deletes — see Undo From History.
